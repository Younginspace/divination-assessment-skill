## 1. 模式选择

| 用户意图 | 使用方式 |
|---|---|
| “简单测一下”“测测我是 INFP 还是 ENTJ”“问几题看四字母结果” | 原创 12 题“四向偏好快照” |
| “大五人格”“更像心理量表”“想看连续维度” | Mini-IPIP 20 题原型 |
| 心理诊断、疾病、招聘筛选、录取或能力判断 | 不运行；改为专业评估或现实信息 |

不得复制、翻译、改写、逆向还原 Myers-Briggs Type Indicator®（MBTI®）官方题目、计分键、常模、报告、图表或标识。开源仓库里出现该名称不代表官方题库已开放：它可能是原创替代题、使用另一个许可，或许可链本身有问题。

四字母代码本身与官方题库是两件事。本 Skill 可以根据原创题目输出 INFP、ENTJ 等独立四字母偏好代码，但产品名、市场标题和功能名不用 `MBTI` 描述本测试，也不得声称官方、等价、认证或授权。免责声明不能补救抄题或商标误导。

## 2. 四向偏好快照

这是随 Skill 一起提供的原创中文反思原型：

- 12 道主问题，每轴 3 题；
- 每题只选 A 或 B，不询问“稍微/非常”等程度，不提供中立项；
- 四个连续轴：
  - 外部激活 ↔ 内部沉淀；
  - 具体取证 ↔ 模式联想；
  - 原则推演 ↔ 价值体察；
  - 计划收束 ↔ 灵活探索。
- 四轴完成后直接输出一个 INFP、ENTJ 等四字母偏好代码；
- 每轴同时输出本轴 3 道二选一的选择占比，例如 2 题支持 I 时显示 `I 67% / E 33%`；
- 可按常见类型学模型给出 `Ti`、`Fi`、`Ne` 等进一步偏好线索，但标明它由四字母代码推导、没有单独测量；
- 不把题内选择占比冒充人口百分位、准确率或统计置信区间。

四轴与字母映射：

| 原创偏好轴 | 字母 |
|---|---|
| 外部激活 ↔ 内部沉淀 | E ↔ I |
| 具体取证 ↔ 模式联想 | S ↔ N |
| 原则推演 ↔ 价值体察 | T ↔ F |
| 计划收束 ↔ 灵活探索 | J ↔ P |

### SOP

1. 运行：

   ```bash
   python3 scripts/score_type_preference.py questions
   ```

2. 开场只说一次“这是一个非官方简单测试”。按返回顺序逐题询问；若宿主有 `ask_user_question@v1.0` 或等效结构化工具，必须用可点击题卡分批收集，不能改成普通文本问答或让用户粘贴答案串。每张题卡展示完整的 A/B 情境，按钮只写必要选项；批量大小服从宿主 schema 上限。仅当该工具不可用或调用失败时，才退回每轮 2—4 道编号文字题。
3. 把回答写入：

   ```json
   {
     "language": "zh-CN",
     "answers": {
       "1": 1,
       "2": 1,
       "3": -1
     }
   }
   ```

   `answers` 必须完整包含 1—12；提交值只允许 `1` 或 `-1`，分别代表 A 或 B。按钮视觉位置可以随机，但提交值必须按选项 id 规范化，不能按左右位置猜分。

4. 计分：

   ```bash
   python3 scripts/score_type_preference.py score \
     <run_dir>/answers.json \
     --output <run_dir>/facts.json
   ```

5. 完成后把 `result.four_letter_preference.code` 放在首屏主标题，紧接着展示四个 `result.scores.*.preference_percentage`。
6. 先展示 `result.derived_function_preferences.plain_sequence_zh`，再展示 `plain_summary_zh`；用户想了解时，用 `stack[].plain_explanation_zh` 逐项解释。禁止只扔出 `Fi → Ne → Si → Te` 让用户自己理解，也不要把功能偏好写成四道独立分数或科学测量结论。

首屏格式：

```markdown
# 你的四字母偏好：INFP

I 67% · N 67% · F 67% · P 67%

进一步偏好（不用记缩写）：
确认自己是否真心认可
→ 探索还有哪些可能
→ 用过往经验核对细节
→ 用计划和标准推动落地

对应术语：确认自己真心认不认可（Fi） → 从一个点展开多种可能（Ne） → 用过往经验核对细节（Si） → 用标准和计划推进（Te）

其中：
- Fi：做决定时，通常先问“这是不是我真正认可和在意的”。这不等于情绪化，而是把个人价值当作重要参照。
- Ne：容易从一个点继续想到其他解释、连接和路线；优势是看到可能性，有时也会因为选项太多而难以马上收束。
- Si：需要稳定或核对时，会参考过去经验、熟悉做法和具体细节；这不等于保守。
- Te：事情必须落地时，会借助目标、优先级、步骤和截止时间推进；排在后面不表示能力差。

这条链表示常见处理顺序，不是能力排名；由四字母偏好代号推导，未单独测量。

[一句贴近事实的概括]

非官方简单测试｜结果来自 12 道原创题，仅供自我探索。
```

由于每轴只有 3 道 A/B 题，选择占比只会是 67% 或 100%。如果产品希望出现更细的 5% 或 10% 梯度，应扩充并验证题库，不能靠加权或四舍五入伪造 `70%`。

## 3. Mini-IPIP 五人格

Mini-IPIP 是 Big Five 的 20 题短量表，每个维度 4 题：

| 英文 | 中文说明 |
|---|---|
| Extraversion | 外向性：社交活跃、表达和寻求刺激的倾向 |
| Agreeableness | 宜人性：合作、信任、体谅与减少对抗的倾向 |
| Conscientiousness | 尽责性：计划、秩序、自律和完成任务的倾向 |
| Neuroticism | 情绪敏感性：更易体验焦虑、压力和负面情绪的倾向 |
| Intellect / Imagination | 想象/开放倾向：好奇、想象、抽象兴趣和新观念偏好 |

它在心理学研究中并不少见，只是在中文大众产品中不像“16 型”那样有易传播的身份标签，所以消费者体感上更少见。

### SOP

```bash
python3 scripts/score_mini_ipip.py questions --language zh-CN
python3 scripts/score_mini_ipip.py score \
  <run_dir>/answers.json \
  --output <run_dir>/facts.json
```

题目回答为 1—5。脚本完成反向计分并输出每维总分、均值、输入 hash 和直线作答等质量提示。

宿主提供结构化问答工具时，20 题同样必须分批显示为 1—5 单选题卡；聊天中只需自然提示进度，不复述原始数字数组。不要在用户未完成全部题卡前生成临时分数或人格描述。

当前中文题是未经本地信效度验证的试译，只能做原型自我反思。正式发布测量产品前要做双向翻译、认知访谈、题目偏差、内部一致性、重测稳定性和本地常模验证。

## 4. 解释边界

- 使用“本次回答更靠近……”“这个信号可以提醒你观察……”；
- 写“你的本次四字母偏好是 INFP”或“暂定 INFP”；不写“你天生就是某类型”“准确率 95%”“你适合/不适合某职业”；
- 不把人格结果用于招聘、晋升、录取、分班、信贷、保险、医疗或关系去留；
- 用户可以不同意结果；优先让其给出反例和具体情境；
- 只生成低风险、可逆的观察建议，例如记录一周中的一个真实例子。
- 解释功能偏好时先说日常行为，再补缩写；不要使用“主导功能、劣势功能、功能堆栈”等术语作为首屏文案。
